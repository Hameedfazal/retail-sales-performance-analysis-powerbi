# Retail Sales Performance & Profitability Analysis

## 📊 Project Overview

This project presents an interactive Retail Sales Analysis Dashboard developed using Microsoft Power BI.

The dashboard provides insights into sales performance, profitability, regional distribution, product performance and salesperson contributions.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📈 Key Performance Indicators

- Total Sales
- Total Profit
- Profit Margin %
- Total Orders
- Average Order Value

## 🔍 Analysis Covered

- Monthly Sales and Profit Trends
- Regional Sales Performance
- Product-wise Sales Analysis
- Payment Method Analysis
- Salesperson Performance
- Profitability Analysis

## 🎛️ Dashboard Features

- Interactive date range selection
- Region and product filters
- Payment method filters
- Salesperson filters
- Interactive charts and KPI cards

## 📁 Project Files

- Power BI Dashboard (.pbix)
- Dataset (.xlsx)
- Dashboard Screenshots (.png)

## 🎯 Project Objective

To transform sales data into meaningful business insights and support data-driven decision-making through interactive visualizations.

## 👨‍💻 Tools & Skills Demonstrated

Power BI | DAX | Power Query | Data Modeling | Data Visualization | Business Intelligence
